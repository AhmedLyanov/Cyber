Современная платформа электронной коммерции для продажи цифровой техники и электроники.

## О проекте

**Cyber** — это полнофункциональный интернет-магазин, ориентированный на продажу электроники и цифровых устройств.

Проект разработан с использованием современной архитектуры разделения клиента и сервера:

- Frontend отвечает за пользовательский интерфейс и взаимодействие с API.
- Backend предоставляет REST API, выполняет авторизацию, работу с базой данных и обработку бизнес-логики.
- MongoDB используется для хранения пользователей, товаров и корзин.
- Stripe предназначен для обработки платежей.
- JWT обеспечивает безопасную аутентификацию пользователей.
